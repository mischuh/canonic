# Canonic marketplace demo

An end-to-end canonic project on a multi-merchant marketplace: one shared SQLite warehouse, 5 merchants, ~24 months of order history, 4 metric contracts, one enforced guardrail, and a full tenant-scoping / role-based-authorization (RBAC) setup demonstrating SPEC-E12.

Full walkthrough, tenant/role table, and the policy-hole/masking/run_sql demos: **[`docs/guides/marketplace.mdx`](../../docs/guides/marketplace.mdx)**.

## Prerequisites

- Python ≥ 3.13, Canonic installed (`pip install -e ../..` from this directory)
- `sqlite3` to create the database from `setup.sql`
- No LLM key needed for `status`/`ingest --bootstrap --headless`/`query`/`mcp start` — every table has a declared primary key, so grain is fully deterministic. Omitting `--headless` still constructs a real LLM drafter and tries to reach it even though there's nothing left to draft; see [docs/guides/marketplace.mdx](../../docs/guides/marketplace.mdx#setup) ("Why `--headless`") for why. `CANONIC_LLM_API_KEY` only matters for optional LLM-backed steps.

## Quickstart

```sh
sqlite3 marketplace.db < setup.sql        # create the database (one-time)
cd examples/marketplace                   # canonic commands must run from here
canonic status
canonic ingest --bootstrap --headless
canonic query --metrics revenue --dimensions status --tenant byte-gadgets
canonic mcp start
```

`--tenant` is a local-development / platform-operator override (SPEC-E12 §7): it always
warns, and it binds no role claim, so a CLI-direct query runs as `roles.yaml`'s
`default_role` (`merchant_viewer`). Without `--tenant` at all, `revenue`/`order_count`/`aov`
queries fail closed with `TENANT_UNRESOLVED` (exit 22) — `tenancy.yaml` sets
`on_missing_principal: deny`.

## What's in here

```
canonic.yaml                    ← SQLite connection (rls_enforced: false), LLM, 5 MCP tokens
setup.sql                       ← DDL + generated seed data (see generate_marketplace_data.py)
semantics/marketplace_db/       ← 7 sources: orders, order_items, customers (scoped),
                                   merchants, dim_date, dim_currency (shared), promotions
                                   (deliberately undeclared — the policy-hole demo)
contracts/metrics/              ← revenue, order_count, aov (ratio), items_sold
contracts/guardrails/           ← orders-excludes-cancelled.yaml
contracts/policies/             ← tenancy.yaml + roles.yaml (SPEC-E12)
knowledge/global/                ← revenue/aov definitions (public/merchant tags) +
                                   platform-margin-notes.md (platform tag, platform_analyst only)
```

The seed data is generated by [`scripts/generate_marketplace_data.py`](../../scripts/generate_marketplace_data.py) (deterministic, seeded — regenerate with
`.venv/bin/python scripts/generate_marketplace_data.py > examples/marketplace/setup.sql` from the repo root).
